4. Nested Loops Visit Every Cell

The outer loop visits rows. The inner loop visits columns in that row.

grid=[[1,2],[3,4]]
for row in range(len(grid)):
 for col in range(len(grid[row])):
  grid[row][col] += 1
1234

Trace row-by-row, cell-by-cell. Final result: [[2,3],[4,5]].

5. Read → Process → Write Back

Indexing can read a cell, and assignment can replace its value. This loop doubles every cell.

grid=[[1,2],[3,4]]
for row in range(len(grid)):
 for col in range(len(grid[row])):
  grid[row][col] = grid[row][col] * 2

# [[2,4],[6,8]]
⚡ Loop Reactor: Locate → Read → Process → Write the new value back to the same coordinate.
